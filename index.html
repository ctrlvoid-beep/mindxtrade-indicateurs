02 — Installation

Dans ATAS en deux minutes

Les indicateurs sont des DLL pour ATAS. Le guide PDF inclus dans chaque archive détaille les réglages recommandés.

  1. 01

    Fermer ATAS, ouvrir le zip

    Téléchargez l'archive depuis la bibliothèque, fermez complètement ATAS, puis décompressez le zip.

  2. 02

    Copier la DLL

    Collez %APPDATA%\ATAS\Indicators dans la barre d'adresse de l'Explorateur et copiez-y le fichier .dll. Avec ATAS X : %APPDATA%\ATAS X\Indicators.

  3. 03

    Relancer et ajouter

    Relancez ATAS, ouvrez un graphique, Ctrl + I, cherchez l'indicateur et ajoutez-le. Le numéro de version s'affiche en bas à gauche du graphique.

Mise à jour : fermez toujours ATAS avant de remplacer la DLL, puis relancez. Les DLL sont compilées pour la version d'ATAS d'octobre 2026 (.NET 10) : si l'indicateur n'apparaît pas dans la liste, votre version d'ATAS est trop différente.
